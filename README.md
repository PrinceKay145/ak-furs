# AK Furs — тестовое задание «AI-ассистент»

Ответы Q1–Q4 пересчитываются из сырых выгрузок (CRM, банковская выписка, справочник цен, переписки) в `answers.json`.
Тексты Q5: записка руководителю — `Q5_memo.md`, ответ клиентке в чате C0010 — `Q5_reply_C0010.md`.

## Запуск

```bash
pip install -r requirements.txt
python solve.py data/ > answers.json
```

Ответы — в stdout, контрольные цифры — в stderr, списки для ручной проверки — в `checks/`. Тесты: `python test_solve.py`.

## Данные

Папки `data/` в репозитории нет: исходные данные просили не публиковать.
Сырые файлы (`01_*.csv`, `02_*.csv`, `03_*.xlsx`, `04_*.zip`, `answers_template.json`) положите в `data/`.

## Q4 и LLM

Сообщения в переписках размечает Claude Code (`claude -p`): где менеджер назвал цену и где пригласил клиента; порядок проверяет код.
Разметка кешируется в `llm_cache.json` по хешу текста чата, так что повторный запуск идёт без обращений к LLM.
Если `claude` недоступен, используется regex-детектор, и в stderr выводится предупреждение.
